GitHub PAT scopes
  • Classic: repo (프라이빗 포함 전체 PR 기능). 구독(Subscribe) 쓰려면 notifications 추가.
  • Fine-grained: 대상 저장소에 Pull requests Read & Write. 제안 적용·파일 업로드는 Contents Read & Write.
토큰은 서비스 워커에서만 사용되며 content script에는 노출되지 않습니다.
