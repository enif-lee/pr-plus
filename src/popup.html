Required permissions

사용에 필요한 Chrome 권한과 GitHub 토큰 스코프입니다.

  • storage PAT·옵션 로컬 저장 (chrome.storage.local)
  • scripting Enterprise 호스트에 content script 등록
  • https://github.com/* github.com PR 리스트·모달 (기본)
  • https://api.github.com/* github.com REST / GraphQL API
  • optional https://*/* Enterprise 웹/API 호스트 (설정에서 허용 요청)
GitHub PAT scopes
  • Classic: repo (프라이빗 포함 전체 PR 기능). 구독(Subscribe) 쓰려면 notifications 추가.
  • Fine-grained: 대상 저장소에 Pull requests Read & Write. 제안(suggestion) 적용·파일 업로드는 Contents Read & Write.
토큰은 서비스 워커에서만 사용되며 content script에는 노출되지 않습니다.
